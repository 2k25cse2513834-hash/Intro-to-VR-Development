# 🎉 Birthday Themed 3D Scene (Blender Project)

## 📌 Project Overview

In this project, I created a simple birthday-themed 3D scene using Blender. The scene includes a table setup with a donut, cake, candle, balloons, and decorative elements to give a festive look.

## 🛠️ What I Built

* Table using cube scaling
* Donut using torus
* Cake using cylinder
* Candle with flame effect
* Balloons using sphere and cylinder
* Confetti for decoration

## 📚 Learning Experience

During this workshop, I learned how to:

* Add and transform basic 3D objects
* Use scale, rotation, and positioning
* Apply materials and colors
* Set up lighting and camera
* Create a complete and structured scene

This project helped me understand the basics of 3D modeling and scene design in Blender.
